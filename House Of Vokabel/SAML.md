## Security Assertion Markup Language

SAML is an XML-based open standard that identity providers use to pass
authorization credentials to service providers.

This means that one set of credentials can be used to log in to multiple websites.

Key points:

- XML-based open standard.
- Used by identity providers (IdP) to communicate with service providers (SP).
- Enables single sign-on (SSO) across different systems.
- Reduces credential sprawl — users maintain one set of credentials for many sites.
