# VirusTotal

**VirusTotal** is a free online service that scans files and URLs
with multiple antivirus engines.

## Features

- Upload files or provide URLs for scanning
- Input file hashes to check against existing reports
- Community insights and comments

## Notes

- Results show detections across ~67 antivirus engines.
- False positives can occur → community comments help clarify.
