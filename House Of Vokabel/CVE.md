# Common Vulnerabilities and Exposures (CVE)

The **CVE Program** acts like a dictionary of vulnerabilities.
It provides a standardized identifier for security issues,
in software and hardware products.

Each vulnerability is assigned a **CVE ID** with a format like `CVE-2024-29988`.
This unique identifier ensures everyone—security researchers, vendors,
and IT teams—refers to the *same* issue consistently.

- Maintained by: **MITRE Corporation**
- Where to search: **CVE Program** and **NVD (National Vulnerability Database)**

## Example

`CVE-2014-0160` — commonly known as **Heartbleed**.
