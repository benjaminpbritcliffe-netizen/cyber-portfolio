
# ATT&CK

MITRE Corporation's Adversarial Tactics, Techniques, and Common Knowledge (ATT&CK) matrices provide access to a database of known tactics, techniques, and procedures (TTPs). This freely available resource ( attack.mitre.org ) tags each technique with a unique ID and places it in one or more tactic categories, such as 

initial access, 

persistence, 

lateral movement, 

or command and control.

The ATT&CK database is contains a navigator tool - The matrix is organized into columns representing different attack tactics across the top, such as Reconnaissance, Resource Development, Initial Access, Execution, Persistence, and others. Within each column, specific techniques associated with each tactic are vertically listed.
