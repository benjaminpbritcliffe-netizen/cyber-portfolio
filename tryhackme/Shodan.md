# Shodan

Shodan is a search engine for devices connected to the Internet.  
It allows you to search for specific types and versions of:

- Servers  
- Networking equipment  
- Industrial control systems  
- IoT devices  

## Example Use Case
You may want to see how many servers are still running **Apache 2.4.1**  
and their distribution across countries.  

By searching for:

```
apache 2.4.1
```

Shodan returns servers with that string in their headers.
