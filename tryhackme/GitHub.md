# GitHub (PoCs & Security Tools)

**GitHub** hosts a wide range of security tools, PoCs, and exploit code related to specific CVEs.

## Use Cases
- Search for **proof-of-concept** implementations for a CVE (e.g., `CVE-2014-0160`)  
- Track active security tool development and community forks  
- Review mitigation scripts and detection tooling

## Tips
- Use advanced search filters (language, stars, updated date) to find higher-quality repos.  
- Review code and issues for safety and reliability before use.
