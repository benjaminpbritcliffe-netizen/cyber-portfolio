# Fuzzing

is an automated software testing method that injects:

- random
- invalid
- or unexpected data into a program

to trigger crashes and expose hidden security vulnerabilities

Input Injection:

A specialized tool called a fuzzer (such as American Fuzzy Lop)
feeds millions of malformed data variants into a target application,
network protocol, or file parser.

Monitoring: The system watches for software crashes, memory leaks,
or unhandled exceptions that signal a weakness.

Exploitation Prevention: Developers use this feedback to patch code flaws,
before malicious hackers can exploit them.
