# Search Engines

"exact phrase":
Double quotes indicate you are looking for pages with exact word / phrase.
For example, one might search for "passive reconnaissance"
to get pages with this exact phrase.

site::
This operator lets you specify domain name to which you want to limit search.
For example, we can search for success stories on TryHackMe
using site:tryhackme.com success stories.

-: Minus sign allows you to omit search results that contain a word or phrase.
For example, you might be interested in learning about the pyramids,
but you don’t want to view tourism websites;
one approach is to search for pyramids -tourism or -tourism pyramids.

filetype:: This search operator for finding files instead of web pages.
Some of the file types you can search for using Google are (PDF),
 (DOC),(XLS), and (PPT). For example, to find cyber security presentations,
 try searching for filetype:ppt cyber security.
