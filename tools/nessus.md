# 🧰 Nessus

## Description

Nessus is a proprietary vulnerability scanner.

## Use Case

- Vulnerability assessments
- Compliance checks


Leveraging the unparalleled accuracy and coverage of Nessus to conduct comprehensive vulnerability scans before
breach simulations begin allows pen testers to identify the areas in need of closest examination. Scans can be
carried out using prefigured policies or configured to meet custom needs.
