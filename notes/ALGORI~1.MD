The second week focuses on data structures and search techniques. You’ll learn how to

During the third week, you’ll dive into pseudocode and asymptotic analysis, including Big-O

to evaluate your programs.

In the fourth week, you’ll focus on linear abstract data structures, such as stacks and

queues, and learn how to implement them using object-oriented programming principles like

classes and data encapsulation.

In week 5, you’ll explore non-linear data structures, focusing on trees and their application in

search algorithms. You’ll write pseudocode for trees, analyse binary search tree properties,

and evaluate their performance in solving search problems.

The following week introduces sorting algorithms and divide-and-conquer strategies. You’ll

design and implement recursive algorithms, analyse the efficiency of different sorting

methods, and practice error handling to make your programs more robust.

The seventh and final week is dedicated to graphs. You’ll learn how to represent graphs

using adjacency lists and adjacency matrices, analyse their properties, and write

pseudocode for various graph algorithms. By the end of this week, you’ll be able to

implement and analyse graph traversal methods and test your solutions against

specifications.

Throughout the course, you’ll participate in hands-on learning through weekly quizzes and

programming assignments, with automated feedback provided via Gradescope. Additionally,

you’ll engage in asynchronous discussions with your peers and tutors, helping to deepen

your understanding of the concepts covered each week.

By the end of this module, you’ll be equipped to solve complex computational problems,

optimize algorithms, and design effective data structures. These are vital skills for success in

any computer science field.

Timetable:

- Week 1: Introduction to Algorithms, problem solving, and writing your first program.
- Week 2: Introduction to Data Structures, search and programming flow-control structures.
- Week 3: Pseudo-code, Asymptotic analysis, Big-O notation and use of function in programming.
- Week 4: Basic linear abstract data structures and their implementations using classes and data encapsulation.
- Week 5: Non linear data structure: Trees and their application to search algorithms. Recursion.
- Week 6: Sorting algorithms and Divide and Conquer algorithmic strategies. Handling errors in a program.
- Week 7: Non-linear data structure: Graphs, how to implement and traverse them.

Learning Objectives:

At the end of this module students will be able to:
