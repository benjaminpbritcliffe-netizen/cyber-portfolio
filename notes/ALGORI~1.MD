# Algorithms

Language: Python

Algorithms are step-by-step procedures or formulas for solving problems or performing tasks. They form the basis of the way we program computers and are methods for taking a set of inputs and processing them to achieve desired outputs.

Components of Algorithms

1. Input: Initial data provided to the algorithm
2. Output: Data produced after computation
3. Definiteness: Each step is clearly defined
4. Finiteness: The algorithm must terminate after a finite number of steps
5. Effectiveness: Each operation must be basic enough to be performed exactly and in a finite amount of time

Properties of Algorithms
• Correctness: An algorithm should produce the correct outputs for given inputs
• Efficiency: Refers to the amount of computational resources the algorithm uses, which includes time complexity and space complexity
• Robustness: The ability of an algorithm to handle unexpected or invalid input gracefully
• Usability: The ease with which the algorithm can be implemented and integrated with other software components

- • Correctness: An algorithm should produce the correct outputs for given inputs
- • Efficiency: Refers to the amount of computational resources the algorithm uses, which includes time complexity and space complexity
- • Robustness: The ability of an algorithm to handle unexpected or invalid input gracefully
- • Usability: The ease with which the algorithm can be implemented and integrated with other software components

Characteristics of Good Algorithms
• Clarity: The steps are straightforward and easy to follow
• Deterministic: Given the same input, the output will always be the same
• Terminating: The algorithm has a clear end point

- • Terminating: The algorithm has a clear end point

## Example

An example of a simple common algorithm used in computer science is the Bubble Sort Algorithm. Please watch the animation all the way through (approx 2.5 minutes).

1. **Start at the beginning of the list**
2. **Compare the first two elements**. If the first element is greater than the second, swap them.
3. **Move to the next pair** of elements and repeat the comparison and swap if necessary.
4. **Continue to the end of the list**. This completes one pass.
5. **Repeat the process for multiple passes**. Each pass will move the next largest element to its correct position.
6. **Stop when no swaps** are made during a pass, indicating the list is sorted.
