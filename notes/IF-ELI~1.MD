Conditional Statements perform different action when condition evaluates true or false.

Can be known as “Branching”

```python
weather = 'Rainy'  
#Answer is Umbrella.

if weather == 'Sunny':
    print('take sunnys')
elif weather == 'Rainy':
    print('Take Umbrella')
else:
    print('Neither')

```

Use the best solution to avoid code duplication.
